# Fingerprint Macro Pad

Turn a Windows fingerprint reader into a **macro pad** once your PC is already unlocked.
Tap the sensor **1 / 2 / 3 / 4 times** to fire four different actions — launch an app,
open a file or URL, send a hotkey, hit a media key, run a saved script, or run a
PowerShell/Batch snippet you paste or drag‑and‑drop in.

A small WPF tray app (.NET 10). Electric‑blue UI with light and dark themes.

## How it works

The Windows Biometric Framework (WinBio) doesn't expose raw touches, only "which
enrolled finger is this." The app opens a read‑only sensor session and turns quick
touches into tap **patterns** (grouped within a configurable window, with a debounce
so a lingering press doesn't over‑count). By default **any finger** triggers macros;
an optional toggle restricts it to fingers that *aren't* your unlock finger.

## Safety

- **Read‑only.** The app only asks the sensor to identify a touch. It never reads a
  fingerprint image, and it contains **no enroll or delete calls** — it cannot add,
  change, or remove any enrolled fingerprint.
- **Pauses while the PC is locked**, so it never competes with the Windows Hello
  unlock screen. Windows always keeps PIN/password as a fallback.

## Requirements

- Windows 10/11 (x64)
- A WinBio fingerprint sensor with a finger enrolled in Windows Hello
- [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0)
- **Runs as administrator** — the sensor only feeds a third‑party session when elevated

## Install

Download `FingerprintMacroPad.exe` from the [latest release](../../releases/latest)
and run it. Use **Start with Windows** in Settings to launch it automatically (elevated,
in the tray, no per‑launch UAC). **Check for updates** in Settings pulls new releases
from GitHub and relaunches.

## Build

```
dotnet build App/App.csproj -c Release
```

Single‑file publish (what the releases ship):

```
dotnet publish App/App.csproj -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true
```

The app icon is generated by `App/tools/make-icon.ps1` (run under Windows PowerShell 5.1).
